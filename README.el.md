# ERATA — διορθωτής κειμένου εκτός σύνδεσης για το πρόγραμμα περιήγησης

Έκδοση: 0.4.0 · Τελευταία ενημέρωση: 27 Νοεμβρίου 2026

Το ERATA είναι μια επέκταση προγράμματος περιήγησης που ελέγχει την ορθογραφία, τη γραμματική, τη στίξη και την τυπογραφία **εξ ολοκλήρου στη συσκευή σας**. Δεν υπάρχει λογαριασμός, διακομιστής ή τηλεμετρία: το κείμενό σας δεν φεύγει ποτέ από τον υπολογιστή σας. Είναι γραμμένο με τη μέθοδο clean-room (βλ. [CLEANROOM.md](CLEANROOM.md)) και διατίθεται με άδεια MIT.

## Λειτουργίες
- Λειτουργεί σε πεδία `textarea`, `input` και `contenteditable`, μεταξύ άλλων σε προηγμένους επεξεργαστές κειμένου. Οι υπογραμμίσεις σχεδιάζονται σε ξεχωριστό επίπεδο και **δεν τροποποιούν ποτέ το DOM της σελίδας**.
- **Ανίχνευση γλώσσας ανά παράγραφο**, ώστε τα αποσπάσματα σε ξένη γλώσσα να μην προκαλούν ψευδείς συναγερμούς.
- **Σε βάθος υποστήριξη της ρουμανικής:** ș/ț με κόμμα από κάτω αντί για σεντίγια, «să/sa», «într-un», «între 5 și 10», κόμματα πριν από «dar/însă», μήνες με μικρό αρχικό, πλεονασμοί, κλιτικά και άλλα.
- **Αποκατάσταση διακριτικών σημείων** (ro, fr, es, pt), που εφαρμόζεται μόνο όταν η διόρθωση είναι σαφής.
- Προσβάσιμοι δείκτες: οι τύποι σφαλμάτων διαφέρουν ως προς το σχήμα της γραμμής (κυματοειδής, συνεχής, διακεκομμένη, στικτή), όχι μόνο ως προς το χρώμα.
- Προσωπικό λεξικό, προσαρμοσμένοι κανόνες regex, διακόπτης ανά ιστότοπο, εισαγωγή/εξαγωγή ρυθμίσεων, εισαγωγή οποιουδήποτε λεξικού Hunspell.
- Σελίδα «Στούντιο κειμένου», «Διόρθωση όλων», βαθμός αναγνωσιμότητας, δύο έλεγχοι ύφους (πολύ μακριές προτάσεις, κοντινές επαναλήψεις).
- Προαιρετική αναδιατύπωση μέσω **τοπικού** μοντέλου (τελικό σημείο συμβατό με OpenAI, μόνο στο `localhost`), απενεργοποιημένη από προεπιλογή.
- Διεπαφή σε 25 γλώσσες: ρουμανικά, αγγλικά, γαλλικά, ιταλικά, ισπανικά, πορτογαλικά, γερμανικά, ουγγρικά, καθώς και οι υπόλοιπες γλώσσες των εθνικών μειονοτήτων της Ρουμανίας (ουκρανικά, τουρκικά, κριμαιοταταρικά, ρωσικά, σερβικά, σλοβακικά, βουλγαρικά, κροατικά, ελληνικά, γίντις, τσεχικά, πολωνικά, αρμενικά, ρουθηνικά, αλβανικά, μακεδονικά, ρομανί). Η γλώσσα της διεπαφής είναι ανεξάρτητη από τη γλώσσα που ελέγχεται.

Συντομεύσεις: `Alt+Shift+F` διορθώνει τα πάντα στο ενεργό πεδίο, `Alt+Shift+E` ενεργοποιεί ή απενεργοποιεί το ERATA στον τρέχοντα ιστότοπο. Πληκτρολόγιο: Alt+Shift+Διάστημα προτάσεις · Alt+Shift+M μενού · Esc κλείσιμο.

## Απόρρητο
Ολόκληρος ο έλεγχος γίνεται μέσα στην επέκταση. Δεν υπάρχει διακομιστής ERATA, λογαριασμός, τηλεμετρία ή αναλυτικά στοιχεία χρήσης και η επέκταση δεν ζητά καμία άδεια δικτύου. Η μοναδική εξαίρεση είναι η προαιρετική αναδιατύπωση μέσω τοπικού μοντέλου, η οποία είναι απενεργοποιημένη από προεπιλογή και μπορεί να στείλει μία πρόταση σε τελικό σημείο στο `localhost`/`127.0.0.1` της επιλογής σας. Οι ρυθμίσεις, το προσωπικό λεξικό και τα εισαγόμενα λεξικά παραμένουν στο `storage.local` και στο IndexedDB στη συσκευή σας. Τα πεδία κωδικού πρόσβασης, e-mail και κάρτας, καθώς και τα πεδία με την επισήμανση `data-erata="off"`, αγνοούνται. Λεπτομέρειες: [PRIVACY.md](PRIVACY.md).

## Εγκατάσταση
Προς το παρόν το ERATA δημιουργείται από τον πηγαίο κώδικα.
```bash
npm i && npm run dicts && npm run build
```
- **Chrome / Edge / Opera:** ανοίξτε το `chrome://extensions`, ενεργοποιήστε τη «Λειτουργία για προγραμματιστές», επιλέξτε «Φόρτωση αποσυσκευασμένης» («Load unpacked») και διαλέξτε το `dist/chrome`.
- **Firefox:** ανοίξτε το `about:debugging`, επιλέξτε «Φόρτωση προσωρινού πρόσθετου» («Load Temporary Add-on») και διαλέξτε το `dist/firefox/manifest.json`.
- **Safari (μέσω Xcode, μόνο macOS):** `xcrun safari-web-extension-converter dist/chrome`, και στη συνέχεια δημιουργήστε και εκτελέστε το παραγόμενο έργο Xcode. Η έκδοση για Safari **δεν έχει δοκιμαστεί** από τον δημιουργό· βλ. [docs/SAFARI.md](docs/SAFARI.md).

## Clean-room
Το ERATA δεν περιέχει και δεν αντλεί τίποτα από τον κώδικα, τους κανόνες (XML/Java), τα δεδομένα ή τα κείμενα μηνυμάτων του LanguageTool ή οποιουδήποτε άλλου διορθωτή. Ο αναλυτής Hunspell, οι κανόνες, ο ανιχνευτής γλώσσας και οι αλγόριθμοι προτάσεων γράφτηκαν από το μηδέν, με βάση δημόσιες περιγραφές των μορφών αρχείων και τη γενική γνώση γραμματικής και τυπογραφίας. Τα ενσωματωμένα λεξικά είναι ανεξάρτητα έργα Hunspell με δικές τους άδειες ([dict/LICENSES.md](dict/LICENSES.md)). Πλήρης μέθοδος: [CLEANROOM.md](CLEANROOM.md).

## Σύγκριση με τις εναλλακτικές (σύντομη και ειλικρινής)
Πλήρης ανάλυση με πηγές και επιφυλάξεις: [docs/COMPARISON.md](docs/COMPARISON.md). Τα στοιχεία για τους ανταγωνιστές συλλέχθηκαν από δημόσιες σελίδες στις 2026-11-18· ό,τι σημειώνεται εκεί ως *μη επαληθευμένο* δεν είναι επιβεβαιωμένο.

- **LanguageTool, Grammarly, Microsoft Editor:** πολύ ευρύτερη κάλυψη γραμματικής στις μεγάλες γλώσσες (το LanguageTool δημοσιεύει αριθμούς κανόνων της τάξης των χιλιάδων για αγγλικά, γαλλικά, γερμανικά, ισπανικά και πορτογαλικά), καθώς και λειτουργίες σαφήνειας και αναδιατύπωσης, Google Docs και κινητά. Από προεπιλογή στέλνουν το κείμενο στα cloud των παρόχων τους. Το ERATA όχι.
- **Harper:** επίσης πλήρως τοπικό και πολύ ενεργό, αλλά μόνο για αγγλικά.
- **Ενσωματωμένος ορθογραφικός έλεγχος του προγράμματος περιήγησης:** τοπικός στη βασική λειτουργία, μόνο ορθογραφία, χωρίς γραμματική.
- **Vale και LTeX+:** εργαλεία για προγραμματιστές, για επεξεργαστές κώδικα και τη γραμμή εντολών, όχι επεκτάσεις προγράμματος περιήγησης.
- **Πού είναι χρήσιμο το ERATA:** τοπική επέκταση προγράμματος περιήγησης που συνδυάζει ορθογραφικό έλεγχο και στοχευμένους κανόνες για ρουμανικά, γαλλικά, ισπανικά, πορτογαλικά και αγγλικά, με αποκατάσταση διακριτικών σημείων, προσαρμοσμένους κανόνες και εισαγόμενα λεξικά. Για τα ρουμανικά, οι πηγές που βρέθηκαν υποδεικνύουν ότι οι καθιερωμένες λύσεις είναι συγκριτικά φτωχές (Microsoft Editor: μόνο ορθογραφία· το LanguageTool σημειώνει τα ρουμανικά ως ανενεργά)· αυτό αντανακλά δημόσιες δηλώσεις, όχι δοκιμή απόδοσης (benchmark).
- **Πού υστερεί:** το ERATA διαθέτει συνολικά περίπου εκατό ελέγχους που γράφτηκαν χειροκίνητα (πρόχειρη καταμέτρηση, χωρίς επαλήθευση). Δεν υπάρχει ακόμη μέτρηση ακρίβειας (precision) και ανάκλησης (recall) σε σώμα κειμένων. Τα ουγγρικά δεν καλύπτονται, ενώ το Microsoft Editor τα καλύπτει και το Grammarly τα αναφέρει σε beta (το βάθος δεν έχει επαληθευτεί).

## Γνωστοί περιορισμοί
- Πολύ λιγότεροι γραμματικοί κανόνες από τους παλαιότερα καθιερωμένους διορθωτές· δεν υπάρχει στατιστικό επίπεδο για σφάλματα πραγματικών λέξεων.
- Χωρίς Google Docs (επεξεργαστής canvas), χωρίς κινητά, χωρίς ενσωμάτωση σε επιτραπέζιες εφαρμογές ή σε επεξεργαστές κειμένου.
- Οι αυτοματοποιημένες δοκιμές σε πρόγραμμα περιήγησης εκτελούνται μόνο σε Chromium. Το Firefox περνά το `web-ext lint`, αλλά δεν έχει εκτελεστεί εδώ σε πρόγραμμα περιήγησης. Το Safari δεν έχει δοκιμαστεί.
- Χωρίς ορθογραφικό έλεγχο για τα ουγγρικά· χωρίς ενσωματωμένο γερμανικό ή ιταλικό λεξικό.
- Χωρίς ανεξάρτητο έλεγχο προσβασιμότητας.
- Το έργο είναι νέο (οι πρώτες εκδόσεις χρονολογούνται από τις 18 Νοεμβρίου 2026): δεν υπάρχει ακόμη βάση χρηστών ή ιστορικό.

## Ανάπτυξη
Απαιτεί Node.js >= 24.
```bash
npm i            # εγκαθιστά τις εξαρτήσεις
npm run dicts    # αντιγράφει τα λεξικά Hunspell στο dict/
npm test         # δοκιμές μονάδων
npm run build    # δημιουργεί τα dist/chrome και dist/firefox
```
Η εντολή `npm run pack` δημιουργεί επιπλέον αρχεία `.zip`.
