# ERATA — զննարկչի անցանց սրբագրիչ

Տարբերակ՝ 0.4.1 · Վերջին թարմացում՝ 2026 թ. նոյեմբերի 28

ERATA-ն զննարկչի ընդլայնում է, որն ստուգում է ուղղագրությունը, քերականությունը, կետադրությունը և տիպոգրաֆիան **ամբողջությամբ ձեր սարքում**։ Չկա հաշիվ, սերվեր կամ հեռաչափություն. ձեր տեքստը երբեք չի լքում ձեր համակարգիչը։ Այն գրված է clean-room եղանակով (տե՛ս [CLEANROOM.md](CLEANROOM.md)) և թողարկված է MIT լիցենզիայով։

## Հնարավորություններ
- Աշխատում է `textarea`, `input` և `contenteditable` դաշտերում, այդ թվում՝ հարուստ տեքստի խմբագրիչներում։ Ընդգծումները գծվում են առանձին շերտով և **երբեք չեն փոփոխում էջի DOM-ը**։
- **Լեզվի հայտնաբերում ըստ պարբերությունների**, ուստի օտար լեզվով հատվածները կեղծ ահազանգեր չեն առաջացնում։
- **Ռումիներենի խորը աջակցություն՝** ստորակետով ș/ț՝ սեդիլի փոխարեն, «să/sa», «într-un», «între 5 și 10», ստորակետ «dar/însă»-ից առաջ, ամիսների անունները փոքրատառով, պլեոնազմներ, կլիտիկներ և այլն։
- **Դիակրիտիկ նշանների վերականգնում** (ro, fr, es, pt), կիրառվում է միայն այնտեղ, որտեղ ուղղումը միանշանակ է։
- Մատչելի նշումներ. սխալների տեսակները տարբերվում են նաև գծի ձևով (ալիքաձև, հոծ, գծիկավոր, կետավոր), ոչ միայն գույնով։
- Անձնական բառարան, սեփական regex կանոններ, կայքի համար անջատիչ, կարգավորումների ներմուծում/արտահանում, ցանկացած Hunspell բառարանի ներմուծում։
- Տեքստային ստուդիայի էջ, «Ուղղել բոլորը», ընթեռնելիության գնահատական, ոճի երկու ստուգում (շատ երկար նախադասություններ, մոտ կրկնություններ)։
- Ընտրովի վերաձևակերպում **տեղական** մոդելով (OpenAI-ի հետ համատեղելի վերջնակետ՝ միայն `localhost`-ում), լռելյայն անջատված է։
- Միջերես 25 լեզվով՝ ռումիներեն, անգլերեն, ֆրանսերեն, իտալերեն, իսպաներեն, պորտուգալերեն, գերմաներեն, հունգարերեն, ինչպես նաև Ռումինիայի ազգային փոքրամասնությունների մյուս լեզուներով (ուկրաիներեն, թուրքերեն, ղրիմթաթարերեն, ռուսերեն, սերբերեն, սլովակերեն, բուլղարերեն, խորվաթերեն, հունարեն, իդիշ, չեխերեն, լեհերեն, հայերեն, ռուսիներեն, ալբաներեն, մակեդոներեն, ռոմաներեն)։ Միջերեսի լեզուն կախված չէ ստուգվող տեքստի լեզվից։

Ստեղնային դյուրանցումներ՝ `Alt+Shift+F`-ը ուղղում է ամեն ինչ ակտիվ դաշտում, `Alt+Shift+E`-ն միացնում կամ անջատում է ERATA-ն ընթացիկ կայքում։ Ստեղնաշար՝ Alt+Shift+Բացատ առաջարկներ · Alt+Shift+M ընտրացանկ · Esc փակել.

Corrections are welcome: https://github.com/chiuta/ERATA/issues) Ամենացածր վստահությունը՝ ռուսիներեն, ռոմաներեն, ղրիմթաթարերեն և իդիշ։ Միջերեսի թարգմանությունը չի ավելացնում տվյալ լեզվի ուղղագրական ստուգում. թե իրականում ինչ է ստուգվում, տե՛ս վերևի աղյուսակում։

## Գաղտնիություն
Ամբողջ ստուգումը կատարվում է ընդլայնման ներսում։ Չկա ERATA սերվեր, հաշիվ, հեռաչափություն կամ վերլուծական տվյալների հավաքագրում, իսկ ընդլայնումը ցանցային թույլտվություն չի պահանջում։ Միակ բացառությունը ընտրովի, լռելյայն անջատված տեղական վերաձևակերպումն է, որը կարող է մեկ նախադասություն ուղարկել ձեր ընտրած `localhost`/`127.0.0.1` հասցեի վերջնակետին։ Կարգավորումները, անձնական բառարանը և ներմուծված բառարանները մնում են ձեր սարքի `storage.local`-ում և IndexedDB-ում։ Գաղտնաբառի, էլ. փոստի և քարտի դաշտերը, ինչպես նաև `data-erata="off"` նշված դաշտերը անտեսվում են։ Մանրամասները՝ [PRIVACY.md](PRIVACY.md)։

## Տեղադրում
Առայժմ ERATA-ն կառուցվում է սկզբնական կոդից։
```bash
npm i && npm run dicts && npm run build
```
- **Chrome / Edge / Opera՝** բացեք `chrome://extensions`, միացրեք «Մշակողի ռեժիմը» (Developer mode), ընտրեք «Բեռնել չփաթեթավորված» (“Load unpacked”) և նշեք `dist/chrome`։
- **Firefox՝** բացեք `about:debugging`, ընտրեք «Բեռնել ժամանակավոր հավելում» (“Load Temporary Add-on”) և նշեք `dist/firefox/manifest.json`։
- **Safari (Xcode-ի միջոցով, միայն macOS)՝** `xcrun safari-web-extension-converter dist/chrome`, ապա կառուցեք և գործարկեք ստեղծված Xcode նախագիծը։ Safari-ի տարբերակը հեղինակի կողմից **փորձարկված չէ**. տե՛ս [docs/SAFARI.md](docs/SAFARI.md)։

## Clean-room
ERATA-ն չի պարունակում և որևէ բան չի ածանցում LanguageTool-ի կամ որևէ այլ ստուգիչի կոդից, կանոններից (XML/Java), տվյալներից կամ հաղորդագրությունների տեքստերից։ Hunspell-ի վերլուծիչը, կանոնները, լեզվի հայտնաբերիչը և առաջարկությունների ալգորիթմները գրվել են զրոյից՝ ձևաչափերի հանրային նկարագրությունների և քերականության ու տիպոգրաֆիայի մասին ընդհանուր գիտելիքների հիման վրա։ Ներառված բառարանները անկախ Hunspell նախագծեր են՝ սեփական լիցենզիաներով ([dict/LICENSES.md](dict/LICENSES.md))։ Ամբողջական մեթոդաբանությունը՝ [CLEANROOM.md](CLEANROOM.md)։

## Համեմատություն այլընտրանքների հետ (կարճ և անկեղծ)
Աղբյուրներով և վերապահումներով ամբողջական նյութը՝ [docs/COMPARISON.md](docs/COMPARISON.md)։ Մրցակիցների մասին փաստերը հավաքվել են հանրային էջերից 2026-11-18-ին. այնտեղ *չստուգված* նշվածը հաստատված չէ։

- **LanguageTool, Grammarly, Microsoft Editor՝** խոշոր լեզուներում քերականական ծածկույթը շատ ավելի լայն է (LanguageTool-ը հրապարակում է հազարներով չափվող կանոնների քանակ անգլերենի, ֆրանսերենի, գերմաներենի, իսպաներենի և պորտուգալերենի համար), ինչպես նաև հստակության և վերաձևակերպման հնարավորություններ, Google Docs-ի և շարժական սարքերի աջակցություն։ Լռելյայն տեքստն ուղարկում են մատակարարների ամպային սերվերներ։ ERATA-ն՝ ոչ։
- **Harper՝** նույնպես լիովին տեղական է և շատ ակտիվ զարգացող, բայց միայն անգլերենի համար։
- **Զննարկչի ներկառուցված ուղղագրության ստուգում՝** հիմնական ռեժիմում տեղական է, միայն ուղղագրություն, առանց քերականության։
- **Vale և LTeX+՝** խմբագրիչների և հրամանի տողի համար նախատեսված մշակողական գործիքներ են, ոչ թե զննարկչի ընդլայնումներ։
- **Որտեղ է ERATA-ն օգտակար՝** տեղական զննարկչային ընդլայնում, որը համատեղում է ուղղագրությունը և նպատակային կանոնները ռումիներենի, ֆրանսերենի, իսպաներենի, պորտուգալերենի և անգլերենի համար՝ դիակրիտիկ նշանների վերականգնմամբ, սեփական կանոններով և ներմուծվող բառարաններով։ Ռումիներենի համար գտնված աղբյուրները թույլ են տալիս ենթադրել, որ գործող լուծումները համեմատաբար թույլ են (Microsoft Editor-ում՝ միայն ուղղագրություն, LanguageTool-ը ռումիներենը նշում է որպես ոչ ակտիվ). սա արտացոլում է հանրային հայտարարությունները, ոչ թե համեմատական չափում։
- **Որտեղ է զիջում՝** ERATA-ն ընդհանուր առմամբ ունի մոտ հարյուր ձեռքով գրված ստուգում (մոտավոր հաշվարկ, առանց աուդիտի)։ Կորպուսի վրա ճշգրտության և լրիվության (precision/recall) չափում դեռ չկա։ Հունգարերենը չի ծածկվում, մինչդեռ Microsoft Editor-ը ծածկում է, իսկ Grammarly-ն այն նշում է բետա փուլում (խորությունը չստուգված)։

## Հայտնի սահմանափակումներ
- Քերականական կանոնները շատ ավելի քիչ են, քան վաղուց գործող ստուգիչներում. իրական բառերով սխալների համար վիճակագրական շերտ չկա։
- Google Docs-ի (canvas խմբագրիչ) աջակցություն չկա, շարժական, աշխատասեղանի կամ տեքստային խմբագրիչների ինտեգրում նույնպես։
- Ավտոմատ զննարկչային թեստերն աշխատում են միայն Chromium-ում։ Firefox-ը հաջողությամբ անցնում է `web-ext lint`-ը, բայց այստեղ զննարկչում չի գործարկվել։ Safari-ն փորձարկված չէ։
- Հունգարերենի ուղղագրական ստուգում չկա. գերմաներենի և իտալերենի ներառված բառարան չկա։
- Անկախ մատչելիության աուդիտ չի եղել։
- Նախագիծը նոր է (առաջին թողարկումները թվագրված են 2026 թ. նոյեմբերի 18-ով). օգտատերերի բազա և ապացուցված փորձ դեռ չկա։

## Մշակում
Պահանջվում է Node.js >= 24։
```bash
npm i            # տեղադրում է կախվածությունները
npm run dicts    # պատճենում է Hunspell-ի բառարանները dict/-ում
npm test         # մոդուլային թեստեր
npm run build    # ստեղծում է dist/chrome և dist/firefox
```
`npm run pack`-ը լրացուցիչ ստեղծում է `.zip` արխիվներ։
