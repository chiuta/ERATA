# ERATA — אָפֿלײַן־קאָרעקטאָר פֿאַר דעם בראַוזער

ווערסיע: 0.4.0 · לעצטע דערהײַנטיקונג: 27 נאָוועמבער 2026

ERATA איז אַ בראַוזער־פֿאַרברײטערונג װאָס קאָנטראָלירט אָרטאָגראַפֿיע, גראַמאַטיק, פּונקטואַציע און טיפּאָגראַפֿיע **גאַנץ אויף אײַער מכשיר**. קײן קאָנטאָ, קײן סערווער, קײן טעלעמעטריע: אײַער טעקסט פֿאַרלאָזט קײנמאָל נישט אײַער קאָמפּיוטער. עס איז געשריבן געװאָרן clean-room (זעט [CLEANROOM.md](CLEANROOM.md)) און פֿאַרעפֿנטלעכט אונטער דער MIT־ליצענץ.

## פֿונקציעס
- אַרבעט אין פֿעלדער פֿון טיפּ `textarea`, `input` און `contenteditable`, אײַנגערעכנט רעדאַקטאָרן פֿאַר פֿאָרמאַטירטן טעקסט. די אונטערשטרײַכונגען װערן געצײכנט אין אַ באַזונדערער שיכט און **טוען קײנמאָל נישט ענדערן דעם DOM פֿון דער זײַט**.
- **דערקענונג פֿון דער שפּראַך אין יעדן אַבזאַץ באַזונדער**, אַזוי אַז אָפּשניטן אין אַן אַנדער שפּראַך רופֿן נישט אַרויס קײן פֿאַלשע אַלאַרמען.
- **טיפֿע שטיצע פֿאַר רומעניש:** ș/ț מיט אַ קאָמע אונטער דער אות אַנשטאָט אַ סעדילע, „să/sa“, „într-un“, „între 5 și 10“, קאָמעס פֿאַר „dar/însă“, חדשים מיט קלײנע אותיות, פּלעאָנאַזמען, קליטיקעס און נאָך.
- **װידערשטעלן פֿון דיאַקריטישע צײכנס** (ro, fr, es, pt), נאָר װוּ די פֿאַרריכטונג איז אײנדײַטיק.
- צוגענגלעכע סימנען: די סאָרטן טעותים אונטערשײדן זיך לויט דער פֿאָרעם פֿון דער ליניע (כוואַליעדיק, פֿאַרבונדן, שטריכלדיק, פּינטלדיק), נישט נאָר לויט קאָליר.
- פּערזענלעך װערטערבוך, אײגענע רעגלען (regex), אַ שאַלטער פֿאַר יעדן װעבזײַט, אימפּאָרט און עקספּאָרט פֿון אײַנשטעלונגען, אימפּאָרט פֿון יעדן Hunspell־װערטערבוך.
- די Text Studio־זײַט, „פֿאַרריכט אַלץ“, אַן אָפּשאַצונג פֿון לײענבאַרקײט, צװײ סטיל־קאָנטראָלן (זײער לאַנגע זאַצן, נאָענטע איבערחזרונגען).
- אָפּציאָנעלע איבערשרײַבונג דורך אַ **לאָקאַלן** מאָדעל (ענדפּונקט װאָס איז קאָמפּאַטיבל מיט OpenAI, נאָר אויף `localhost`), לויט ברירת־מחדל אויסגעשאַלט.
- אינטערפֿייס אין 25 שפּראַכן: רומעניש, ענגליש, פֿראַנצויזיש, איטאַליעניש, שפּאַניש, פּאָרטוגעזיש, דײַטש, אונגעריש, פּלוס די אַנדערע שפּראַכן פֿון די נאַציאָנאַלע מינדערהײטן פֿון רומעניע (אוקראַיִניש, טערקיש, קרים־טאַטאַריש, רוסיש, סערביש, סלאָוואַקיש, בולגאַריש, קראָאַטיש, גריכיש, ייִדיש, טשעכיש, פּויליש, אַרמעניש, רוסיניש, אַלבאַניש, מאַקעדאָניש, ראָמאַני). די שפּראַך פֿון אינטערפֿייס איז אומאָפּהענגיק פֿון דער שפּראַך װאָס װערט קאָנטראָלירט.

## פּריוואַטקײט
די גאַנצע קאָנטראָל געשעט אינערהאַלב דער פֿאַרברײטערונג. עס איז ניטאָ קײן ERATA־סערווער, קאָנטאָ, טעלעמעטריע אָדער אַנאַליטיק, און די פֿאַרברײטערונג בעט נישט קײן נעץ־דערלויבעניש. די איינציקע אויסנאַם איז די אָפּציאָנעלע, לויט ברירת־מחדל אויסגעשאַלטענע לאָקאַלע איבערשרײַבונג, װאָס קען שיקן איין זאַץ צו אַן ענדפּונקט אויף `localhost`/`127.0.0.1` װאָס איר קלײַבט אויס. די אײַנשטעלונגען, דאָס פּערזענלעכע װערטערבוך און די אימפּאָרטירטע װערטערביכער בלײַבן אין `storage.local` און IndexedDB אויף אײַער מכשיר. פֿעלדער פֿאַר פּאַראָלן, E-mail און קאַרטלען, אַזוי װי פֿעלדער מיט `data-erata="off"`, װערן איגנאָרירט. פּרטים: [PRIVACY.md](PRIVACY.md).

## אינסטאַלאַציע
ERATA װערט דערװײַל געבויט פֿון קוואַל־קאָד.
```bash
npm i && npm run dicts && npm run build
```
- **Chrome / Edge / Opera:** עפֿנט `chrome://extensions`, שאַלט אײַן „Developer mode“, קלײַבט אויס „Load unpacked“ און קלײַבט אויס `dist/chrome`.
- **Firefox:** עפֿנט `about:debugging`, קלײַבט אויס „Load Temporary Add-on“ און קלײַבט אויס `dist/firefox/manifest.json`.
- **Safari (דורך Xcode, נאָר macOS):** `xcrun safari-web-extension-converter dist/chrome`, דערנאָך בויט און פֿירט אויס דאָס געשאַפֿענע Xcode־פּראָיעקט. די Safari־װערסיע איז **נישט געטעסט געװאָרן** דורכן מחבר; זעט [docs/SAFARI.md](docs/SAFARI.md).

## Clean-room
ERATA אַנטהאַלט און לײטן אָפּ נישט קײן זאַך פֿון דעם קאָד, די רעגלען (XML/Java), די דאַטן אָדער די מעלדונג־טעקסטן פֿון LanguageTool אָדער פֿון קײן אַנדער קאָרעקטאָר. דער Hunspell־פּאַרסער, די רעגלען, דער שפּראַך־דעטעקטאָר און די אַלגאָריתמען פֿאַר פֿאָרשלאָגן זענען געשריבן געװאָרן פֿון אָנהײב אָן לויט עפֿנטלעכע באַשרײַבונגען פֿון די פֿאָרמאַטן און אַלגעמײנע װיסן װעגן גראַמאַטיק און טיפּאָגראַפֿיע. די אײַנגעשלאָסענע װערטערביכער זענען אומאָפּהענגיקע Hunspell־פּראָיעקטן מיט זײערע אײגענע ליצענצן ([dict/LICENSES.md](dict/LICENSES.md)). פֿולע מעטאָד: [CLEANROOM.md](CLEANROOM.md).

## פֿאַרגלײַך מיט אַלטערנאַטיװן (קורץ און ערלעך)
פֿולער באַריכט מיט קוואַלן און פֿאָרבאַהאַלטן: [docs/COMPARISON.md](docs/COMPARISON.md). פֿאַקטן װעגן קאָנקורענטן זענען אײַנגעזאַמלט געװאָרן פֿון עפֿנטלעכע זײַטן דעם 2026-11-18; אַלץ װאָס איז דאָרט אָנגעצײכנט *unverified* איז נישט באַשטעטיקט.

- **LanguageTool, Grammarly, Microsoft Editor:** פֿיל גרעסערע דעקונג פֿון גראַמאַטיק אין די גרויסע שפּראַכן (LanguageTool פּובליקירט צאָלן פֿון רעגלען אין די טויזנטער פֿאַר ענגליש, פֿראַנצויזיש, דײַטש, שפּאַניש און פּאָרטוגעזיש), פּלוס פֿונקציעס פֿאַר קלאָרקײט און איבערשרײַבן, Google Docs און מאָביל. זײ שיקן טעקסט צו די קלאַוד־סערווערס פֿון די פֿאַרקויפֿער לויט ברירת־מחדל. ERATA טוט עס נישט.
- **Harper:** אויך גאַנץ לאָקאַל און זײער אַקטיװ, אָבער נאָר ענגליש.
- **די אײַנגעבויטע אָרטאָגראַפֿיע־קאָנטראָל פֿון בראַוזער:** לאָקאַל אין איר גרונט־רעזשים, נאָר אָרטאָגראַפֿיע, קײן גראַמאַטיק נישט.
- **Vale און LTeX+:** אינסטרומענטן פֿאַר אַנטוויקלער, פֿאַר רעדאַקטאָרן און דער באַפֿעל־שורה, נישט קײן בראַוזער־פֿאַרברײטערונגען.
- **װוּ ERATA איז ניצלעך:** אַ לאָקאַלע בראַוזער־פֿאַרברײטערונג װאָס פֿאַראײניקט אָרטאָגראַפֿיע מיט ציל־געריכטע רעגלען פֿאַר רומעניש, פֿראַנצויזיש, שפּאַניש, פּאָרטוגעזיש און ענגליש, מיט װידערשטעלן פֿון דיאַקריטישע צײכנס, אײגענע רעגלען און אימפּאָרטירטע װערטערביכער. פֿאַר רומעניש װײַזן די געפֿונענע קוואַלן אַז די עטאַבלירטע קאָנקורענטן זענען פֿאַרגלײַכנדיק דאַר (נאָר אָרטאָגראַפֿיע אין Microsoft Editor; LanguageTool צײכנט אָן רומעניש װי אומאַקטיװ); דאָס שפּיגלט אָפּ עפֿנטלעכע דערקלערונגען, נישט קײן בענטשמאַרק.
