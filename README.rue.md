# ERATA — офлайн-коректор про браузер

Верзія: 0.4.1 · Остатня актуалізація: 28 новембра 2026

ERATA є додаток до браузера, котрый перевіряє правопис, ґраматику, пунктуацію і типоґрафію **цілком на вашім пристрою**. Нема конта, сервера ани телеметрії: ваш текст ніколи не выходить з вашого компутера. Написаный є методом clean-room (глядьте [CLEANROOM.md](CLEANROOM.md)) і выданый під ліцензіёв MIT.

## Функції
- Працує в полях `textarea`, `input` і `contenteditable`, включно з редакторами форматованого тексту. Підчеркованя ся малюють в окремім шарі і **не міняют DOM сторінкы**.
- **Розпознаваня языка по абзацах**, тому частины в іншім языку не выкликують хыбны попередженя.
- **Глубока підтримка румуньского языка:** ș/ț з комов замість седілі, «să/sa», «într-un», «între 5 și 10», кома перед «dar/însă», назвы місяців з малов буквов, плеоназмы, клітикы і дале.
- **Одновлёваня діакритичных знаків** (ro, fr, es, pt), лем там, де поправка є однозначна.
- Приступны значкы: типы хыб ся розрізняют ай формов лінії (хвилькова, суцільна, штрихова, точкова), не лем кольором.
- Особистый словник, властны правила regex, перемикач про окремы сайты, імпорт/експорт наставлїня, імпорт будь-якого словника Hunspell.
- Сторінка Студіо тексту, «Поправити вшытко», індекс чітности, дві провіркы стилю (барз довгы речіня, близкы повторованя).
- Выбірове переформулованя через **локалну** модель (кінцева точка, сумісна з OpenAI, лем на `localhost`), по замовчаню выпнуте.
- Інтерфейс в 25 языках: румуньскый, анґліцькый, французькый, італьскый, іспаньскый, португальскый, нїмецькый, мадярьскый, плюс іншы языкы националных меншын Румуньска (україньскый, турецькый, кримскотатарьскый, росийскый, сербскый, словацькый, болгарьскый, хорватьскый, ґрецькый, ідіш, чеськый, польскый, вірменьскый, русиньскый, албаньскый, македоньскый, ромськый). Язык інтерфейсу є незалежный од языка провіряного тексту.

Клавішовы скороченя: `Alt+Shift+F` поправляє вшытко в актівнім полю, `Alt+Shift+E` вкляпає або выкляпає ERATA на актуалнім сайті. Клавіатура: Alt+Shift+Пробіл порады · Alt+Shift+M меню · Esc закрыти.

## Переклады
Інтерфейс, тот README і сторінка презентації суть в 25 языках. Осем з них (ro, en, fr, it, es, pt, de, hu) суть основны языкы проєкту, іншых сімнадцять додано в 0.4.1. **Машинный переклад, іщі не перевірёваный носієм языка. Поправкы вітаны: https://github.com/chiuta/ERATA/issues** (Machine translation, not yet reviewed by a native speaker. Corrections are welcome: https://github.com/chiuta/ERATA/issues) Найменша певность: русиньскый, ромськый, кримскотатарьскый і ідіш. Переклад інтерфейсу не додає провіркы правопису того языка: глядьте таблицю выше, што ся справды провіряє.

## Приватность
Вся провірка ся діє в додатку. Нема сервера ERATA, конта, телеметрії ани аналітикы, а додаток не просить доступ до мережі. Єдиный выняток — выбірове локалне переформулованя, по замовчаню выпнуте, котре може послати одно речіня на кінцеву точку на `localhost`/`127.0.0.1`, котру собі выберете. Наставлїня, особистый словник і імпортованы словникы зостають в `storage.local` і IndexedDB на вашім пристрою. Поля про пароли, e-mail і карту, а такой поля з познаком `data-erata="off"`, ся ігноруют. Подробности: [PRIVACY.md](PRIVACY.md).

## Інсталація
Покы што ERATA треба збудовати зо зыходного кода.
```bash
npm i && npm run dicts && npm run build
```
- **Chrome / Edge / Opera:** одкрыйте `chrome://extensions`, включте режим розробника («Developer mode»), выберьте «Load unpacked» і укажьте `dist/chrome`.
- **Firefox:** одкрыйте `about:debugging`, выберьте «Load Temporary Add-on» і укажьте `dist/firefox/manifest.json`.
- **Safari (через Xcode, лем macOS):** `xcrun safari-web-extension-converter dist/chrome`, потім збудуйте і запустьте створеный проєкт Xcode. Верзія про Safari **не была тестована** автором; глядьте [docs/SAFARI.md](docs/SAFARI.md).

## Clean-room
ERATA не містить і не выводить ніч з кода, правил (XML/Java), даных або текстів повідомлїнь LanguageTool або якогось іншого коректора. Парсер Hunspell, правила, детектор языка і алґоритмы порад были написаны од нуля, на основі публічных описів формату і загальных знань про ґраматику і типоґрафію. Вбудованы словникы суть незалежны проєкты Hunspell з властныма ліцензіями ([dict/LICENSES.md](dict/LICENSES.md)). Повна методика: [CLEANROOM.md](CLEANROOM.md).

## Порівнаня з альтернативами (коротко і чесно)
Повный опис з жерелами і застереженями: [docs/COMPARISON.md](docs/COMPARISON.md). Факты про конкурентів были зобраны з публічных сторінок 2026-11-18; што там позначене як *неперевірене*, тото не потверджене.

- **LanguageTool, Grammarly, Microsoft Editor:** значно ширше покрытя ґраматикы у великых языках (LanguageTool публікує чісла правил в тисячах про анґліцькый, французькый, нїмецькый, іспаньскый і португальскый язык), к тому функції ясности і переформулованя, Google Docs і мобілны пристрої. Они по замовчаню шлють текст до хмар выробцїв. ERATA — ні.
- **Harper:** тіж цілком локалный і барз актівно розвиваный, але лем про анґліцькый язык.
- **Вбудована провірка правопису браузера:** локална в основнім режимі, лем правопис, без ґраматикы.
- **Vale і LTeX+:** інструменты про розвойовників (про редакторы і командный рядок), не розшырїня браузера.
- **Де ERATA корисна:** локалный додаток до браузера, котрый споює правопис і цілены правила про румуньскый, французькый, іспаньскый, португальскый і анґліцькый язык, з одновлёванём діакритикы, властныма правилами і імпортованыма словниками. Про румуньскый язык найдены жерела наводят на то, же сучасны рішіня суть порівняно слабы (в Microsoft Editor лем правопис; LanguageTool позначує румуньскый як неактівный); тото одповідать публічным заявам, не порівнюючому змерінью.
- **Де програє:** в ERATA є приблизно сто ручно написаных провірок усього (грубый одгад, не аудитованый). Іщі нема змерінь точности і повноты на корпусі. Мадярьскый язык не є покрытый, хоць Microsoft Editor ёго покрывать, а Grammarly ёго мать в бета-версії (глубина неперевірена).

## Знамы обмеженя
- Значно менше ґраматічных правил як в давно етаблованых коректорах; нема статістічного шару про хыбы в реалных словах.
- Нема Google Docs (редактор на canvas), нема мобілной, десктопной або інтеґрації з текстовыма процесорами.
- Автоматізованы тесты браузера бігают лем на Chromium. Firefox проходить `web-ext lint`, але туто ся в браузері не пущав. Safari не тестованый.
- Нема провіркы правопису мадярьского языка; нема вбудованого нїмецького ани італьского словника.
- Нема незалежного аудиту приступности.
- Проєкт є новый (першы выданя з 18 новембра 2026): іщі нема ани базы ужывателів, ани доказаной історії.

## Розробка
Потребує Node.js >= 24.
```bash
npm i            # встановлює залежности
npm run dicts    # копіює словникы Hunspell до dict/
npm test         # модулны тесты
npm run build    # творит dist/chrome і dist/firefox
```
Команда `npm run pack` додатково створює архівы `.zip`.
