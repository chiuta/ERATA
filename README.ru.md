# ERATA — офлайн-корректор для браузера

Версия: 0.4.1 · Последнее обновление: 28 ноября 2026 г.

ERATA — расширение для браузера, которое проверяет орфографию, грамматику, пунктуацию и типографику **полностью на вашем устройстве**. Здесь нет ни учётной записи, ни сервера, ни телеметрии: ваш текст никогда не покидает компьютер. Код написан по методу clean-room (см. [CLEANROOM.md](CLEANROOM.md)) и распространяется под лицензией MIT.

## Возможности
- Работает в полях `textarea`, `input` и `contenteditable`, включая визуальные редакторы. Подчёркивания рисуются в отдельном слое и **никогда не изменяют DOM страницы**.
- **Определение языка для каждого абзаца**, поэтому фрагменты на иностранных языках не вызывают ложных срабатываний.
- **Глубокая поддержка румынского языка:** ș/ț с запятой снизу вместо седили, «să/sa», «într-un», «între 5 și 10», запятые перед «dar/însă», названия месяцев со строчной буквы, плеоназмы, клитики и многое другое.
- **Восстановление диакритических знаков** (ro, fr, es, pt) — только там, где исправление однозначно.
- Доступные маркеры: типы ошибок различаются формой линии (волнистая, сплошная, штриховая, точечная), а не только цветом.
- Личный словарь, собственные правила на регулярных выражениях, переключатель для отдельных сайтов, импорт и экспорт настроек, импорт любого словаря Hunspell.
- Страница Text Studio, функция «Исправить всё», оценка удобочитаемости, две стилистические проверки (очень длинные предложения, близкие повторы).
- Необязательное переписывание с помощью **локальной** модели (конечная точка, совместимая с OpenAI, только на `localhost`); по умолчанию отключено.
- Интерфейс на 25 языках: румынском, английском, французском, итальянском, испанском, португальском, немецком, венгерском, а также на других языках национальных меньшинств Румынии (украинском, турецком, крымскотатарском, русском, сербском, словацком, болгарском, хорватском, греческом, идише, чешском, польском, армянском, русинском, албанском, македонском, романи). Язык интерфейса не зависит от языка проверяемого текста.

Горячие клавиши: `Alt+Shift+F` исправляет всё в активном поле, `Alt+Shift+E` включает и отключает ERATA на текущем сайте. Клавиши: Alt+Shift+Пробел — варианты · Alt+Shift+M — меню · Esc — закрыть.

## Конфиденциальность
Вся проверка выполняется внутри расширения. У ERATA нет ни сервера, ни учётных записей, ни телеметрии, ни аналитики, и расширение не запрашивает разрешений на доступ к сети. Единственное исключение — необязательное локальное переписывание, по умолчанию отключённое: оно может отправить одно предложение на выбранную вами конечную точку на `localhost`/`127.0.0.1`. Настройки, личный словарь и импортированные словари хранятся в `storage.local` и IndexedDB на вашем устройстве. Поля паролей, адресов электронной почты и банковских карт, а также поля с атрибутом `data-erata="off"` игнорируются. Подробнее: [PRIVACY.md](PRIVACY.md).

## Установка
Пока ERATA собирается из исходного кода.
```bash
npm i && npm run dicts && npm run build
```
- **Chrome / Edge / Opera:** откройте `chrome://extensions`, включите «Режим разработчика», выберите «Загрузить распакованное расширение» и укажите папку `dist/chrome`.
- **Firefox:** откройте `about:debugging`, выберите «Загрузить временное дополнение» и укажите файл `dist/firefox/manifest.json`.
- **Safari (через Xcode, только macOS):** `xcrun safari-web-extension-converter dist/chrome`, затем соберите и запустите созданный проект Xcode. Сборка для Safari автором **не тестировалась**; см. [docs/SAFARI.md](docs/SAFARI.md).

## Clean-room
ERATA не содержит и не заимствует ничего из кода, правил (XML/Java), данных или текстов сообщений LanguageTool или любой другой программы проверки. Парсер Hunspell, правила, определитель языка и алгоритмы подсказок написаны с нуля на основе публичных описаний форматов и общих знаний о грамматике и типографике. Встроенные словари — независимые проекты Hunspell со своими лицензиями ([dict/LICENSES.md](dict/LICENSES.md)). Полное описание метода: [CLEANROOM.md](CLEANROOM.md).

## Сравнение с альтернативами (коротко и честно)
Полный разбор с источниками и оговорками: [docs/COMPARISON.md](docs/COMPARISON.md). Сведения о конкурентах собраны с публичных страниц 2026-11-18; всё, что отмечено там как *не проверено*, не подтверждено.

- **LanguageTool, Grammarly, Microsoft Editor:** значительно более широкий охват грамматики в основных языках (LanguageTool публикует число правил в тысячах для английского, французского, немецкого, испанского и португальского), а также функции повышения ясности текста и переписывания, поддержка Google Docs и мобильных устройств. По умолчанию они отправляют текст в облака своих разработчиков. ERATA этого не делает.
- **Harper:** тоже полностью локальный и очень активно развивается, но поддерживает только английский.
- **Встроенная проверка орфографии браузера:** в базовом режиме локальная, только орфография, без грамматики.
- **Vale и LTeX+:** инструменты для разработчиков (редакторы и командная строка), а не расширения для браузера.
- **Чем полезна ERATA:** локальное расширение для браузера, сочетающее проверку орфографии и целевые правила для румынского, французского, испанского, португальского и английского языков, с восстановлением диакритики, собственными правилами и импортируемыми словарями. Для румынского найденные источники позволяют предположить, что у существующих решений охват сравнительно скромный (в Microsoft Editor — только орфография; LanguageTool помечает румынский как неактивный); это отражает публичные заявления, а не сравнительное тестирование.
- **Где она уступает:** в ERATA всего порядка ста написанных вручную проверок (приблизительная оценка, не прошедшая аудит). Измерений точности и полноты на текстовом корпусе пока нет. Венгерский не поддерживается, тогда как Microsoft Editor его поддерживает, а Grammarly указывает его как бета-функцию (глубина не проверена).

## Известные ограничения
- Гораздо меньше грамматических правил, чем у давно существующих средств проверки; нет статистического слоя для ошибок в реально существующих словах.
- Нет Google Docs (редактор на canvas), нет мобильной версии, нет интеграции с настольными приложениями и текстовыми процессорами.
- Автоматические браузерные тесты выполняются только на Chromium. Firefox проходит `web-ext lint`, но в браузере здесь не запускался. Safari не тестировался.
- Нет проверки орфографии для венгерского; нет встроенного словаря для немецкого и итальянского.
- Независимый аудит доступности не проводился.
- Проект новый (первые релизы датированы 18 ноября 2026 г.): пользовательской базы и опыта эксплуатации пока нет.

## Разработка
Требуется Node.js >= 24.
```bash
npm i            # установить зависимости
npm run dicts    # скопировать словари Hunspell в dict/
npm test         # модульные тесты
npm run build    # создаёт dist/chrome и dist/firefox
```
`npm run pack` дополнительно создаёт архивы `.zip`.
