# ERATA — офлайн-коректор для браузера

Версія: 0.4.0 · Останнє оновлення: 27 листопада 2026 р.

ERATA — це розширення для браузера, яке перевіряє правопис, граматику, пунктуацію та типографіку **повністю на вашому пристрої**. Жодного облікового запису, сервера чи телеметрії: ваш текст ніколи не залишає комп’ютера. Розширення написане за методом clean-room (див. [CLEANROOM.md](CLEANROOM.md)) і розповсюджується за ліцензією MIT.

## Можливості
- Працює в полях `textarea`, `input` та `contenteditable`, зокрема в багатофункціональних редакторах. Підкреслення малюються в окремому шарі й **ніколи не змінюють DOM сторінки**.
- **Визначення мови для кожного абзацу**, тому уривки іншою мовою не спричиняють хибних спрацювань.
- **Поглиблена підтримка румунської:** ș/ț із комою знизу замість седиля, «să/sa», «într-un», «între 5 și 10», коми перед «dar/însă», назви місяців з малої літери, плеоназми, клітики та інше.
- **Відновлення діакритичних знаків** (ro, fr, es, pt), що застосовується лише там, де виправлення однозначне.
- Доступні маркери: типи помилок відрізняються формою лінії (хвиляста, суцільна, штрихова, крапкова), а не лише кольором.
- Особистий словник, власні правила на основі регулярних виразів, перемикач для окремого сайту, імпорт і експорт налаштувань, імпорт будь-якого словника Hunspell.
- Сторінка Text Studio, «Виправити все», оцінка читабельності, дві перевірки стилю (надто довгі речення, близькі повтори).
- Необов’язкове переписування за допомогою **локальної** моделі (кінцева точка, сумісна з OpenAI, лише на `localhost`), типово вимкнене.
- Інтерфейс 25 мовами: румунською, англійською, французькою, італійською, іспанською, португальською, німецькою, угорською, а також іншими мовами національних меншин Румунії (українською, турецькою, кримськотатарською, російською, сербською, словацькою, болгарською, хорватською, грецькою, їдиш, чеською, польською, вірменською, русинською, албанською, македонською, ромською). Мова інтерфейсу не залежить від мови, яку перевіряють.

Гарячі клавіші: `Alt+Shift+F` виправляє все в активному полі, `Alt+Shift+E` вмикає або вимикає ERATA на поточному сайті. Клавіатура: Alt+Shift+Пробіл підказки · Alt+Shift+M меню · Esc закрити.

## Конфіденційність
Уся перевірка відбувається всередині розширення. Немає ні сервера ERATA, ні облікових записів, ні телеметрії чи аналітики, а розширення не запитує жодних мережевих дозволів. Єдиний виняток — необов’язкове, типово вимкнене локальне переписування, яке може надіслати одне речення на кінцеву точку `localhost`/`127.0.0.1`, яку ви обираєте самі. Налаштування, особистий словник та імпортовані словники зберігаються в `storage.local` та IndexedDB на вашому пристрої. Поля для паролів, електронної пошти та банківських карток, а також поля з позначкою `data-erata="off"` ігноруються. Докладніше: [PRIVACY.md](PRIVACY.md).

## Встановлення
Наразі ERATA збирається з вихідного коду.
```bash
npm i && npm run dicts && npm run build
```
- **Chrome / Edge / Opera:** відкрийте `chrome://extensions`, увімкніть режим розробника, виберіть «Завантажити розпаковане розширення» та вкажіть `dist/chrome`.
- **Firefox:** відкрийте `about:debugging`, виберіть «Завантажити тимчасовий додаток» та вкажіть `dist/firefox/manifest.json`.
- **Safari (через Xcode, лише macOS):** `xcrun safari-web-extension-converter dist/chrome`, потім зберіть і запустіть згенерований проєкт Xcode. Автор **не тестував** збірку для Safari; див. [docs/SAFARI.md](docs/SAFARI.md).

## Clean-room
ERATA не містить і не запозичує нічого з коду, правил (XML/Java), даних чи текстів повідомлень LanguageTool або будь-якого іншого засобу перевірки. Парсер Hunspell, правила, мовний детектор і алгоритми підказок написано з нуля на основі публічних описів формату та загальних знань із граматики й типографіки. Вбудовані словники — це незалежні проєкти Hunspell зі своїми ліцензіями ([dict/LICENSES.md](dict/LICENSES.md)). Повний опис методу: [CLEANROOM.md](CLEANROOM.md).

## Порівняння з альтернативами (коротко й чесно)
Повний опис із джерелами та застереженнями: [docs/COMPARISON.md](docs/COMPARISON.md). Відомості про конкурентів зібрано з публічних сторінок 18 листопада 2026 року; усе, що там позначено як *не підтверджено*, підтвердження не має.

- **LanguageTool, Grammarly, Microsoft Editor:** набагато ширше охоплення граматики для основних мов (LanguageTool публікує кількість правил у тисячах для англійської, французької, німецької, іспанської та португальської), а також функції покращення ясності й переписування, підтримка Google Docs і мобільних пристроїв. Типово вони надсилають текст у хмари своїх виробників. ERATA — ні.
- **Harper:** теж повністю локальний і дуже активно розвивається, але лише для англійської.
- **Вбудована перевірка правопису браузера:** локальна в базовому режимі, лише правопис, без граматики.
- **Vale і LTeX+:** інструменти для розробників, призначені для редакторів і командного рядка, а не розширення для браузерів.
- **Де ERATA корисна:** локальне розширення для браузера, що поєднує перевірку правопису та прицільні правила для румунської, французької, іспанської, португальської й англійської, з відновленням діакритичних знаків, власними правилами та імпортованими словниками. Щодо румунської, знайдені джерела дають підстави вважати, що наявні рішення порівняно слабкі (у Microsoft Editor — лише правопис; LanguageTool позначає румунську як неактивну); це відображає публічні заяви, а не вимірювання за еталонним тестом.
- **Де вона програє:** загалом ERATA має близько сотні написаних вручну перевірок (приблизний підрахунок, не аудитований). Вимірювання точності й повноти на корпусі ще не проводилося. Угорську не охоплено, тоді як Microsoft Editor її підтримує, а Grammarly згадує її як бета-версію (глибина не підтверджена).

## Відомі обмеження
- Набагато менше граматичних правил, ніж у давно усталених засобів перевірки; немає статистичного шару для помилок, що дають існуюче слово.
- Немає Google Docs (редактор на canvas), немає мобільних пристроїв, немає інтеграції з настільними застосунками чи текстовими процесорами.
- Автоматизовані браузерні тести виконуються лише в Chromium. Firefox проходить `web-ext lint`, але тут у браузері не запускався. Safari не тестувався.
- Немає перевірки правопису для угорської; немає вбудованого німецького чи італійського словника.
- Немає незалежного аудиту доступності.
- Проєкт новий (перші випуски датовано 18 листопада 2026 року): ще немає ні бази користувачів, ні напрацьованої репутації.

## Розробка
Потрібен Node.js >= 24.
```bash
npm i            # установити залежності
npm run dicts    # скопіювати словники Hunspell у dict/
npm test         # модульні тести
npm run build    # створює dist/chrome і dist/firefox
```
`npm run pack` додатково створює архіви `.zip`.
