# ERATA — офлајн коректор за прегледач

Верзија: 0.4.1 · Последње ажурирање: 28. новембар 2026.

ERATA је проширење за прегледач које проверава правопис, граматику, интерпункцију и типографију **у потпуности на вашем уређају**. Нема налога, сервера ни телеметрије: ваш текст никада не напушта рачунар. Написана је по clean-room методи (погледајте [CLEANROOM.md](CLEANROOM.md)) и објављена под MIT лиценцом.

## Функције
- Ради у пољима `textarea`, `input` и `contenteditable`, укључујући напредне уређиваче. Подвлаке се исцртавају на засебном слоју и **никада не мењају DOM странице**.
- **Препознавање језика по пасусима**, па одломци на страном језику не изазивају лажне узбуне.
- **Дубока подршка за румунски:** ș/ț са зарезом испод уместо седиље, „să/sa“, „într-un“, „între 5 și 10“, зарези испред „dar/însă“, називи месеци малим словом, плеоназми, клитике и друго.
- **Враћање дијакритичких знакова** (ro, fr, es, pt), које се примењује само тамо где је исправка недвосмислена.
- Приступачне ознаке: врсте грешака разликују се обликом линије (таласаста, пуна, испрекидана, тачкаста), а не само бојом.
- Лични речник, сопствена правила са регуларним изразима, прекидач по сајту, увоз и извоз подешавања, увоз било ког Hunspell речника.
- Страница Text Studio, „Исправи све“, оцена читљивости, две стилске провере (веома дуге реченице, блиска понављања).
- Необавезно преформулисање помоћу **локалног** модела (крајња тачка компатибилна са OpenAI, само на `localhost`), подразумевано искључено.
- Интерфејс на 25 језика: румунском, енглеском, француском, италијанском, шпанском, португалском, немачком, мађарском, као и на осталим језицима националних мањина у Румунији (украјинском, турском, кримскотатарском, руском, српском, словачком, бугарском, хрватском, грчком, јидишу, чешком, пољском, јерменском, русинском, албанском, македонском, ромском). Језик интерфејса не зависи од језика текста који се проверава.

Пречице: `Alt+Shift+F` исправља све у активном пољу, `Alt+Shift+E` укључује или искључује ERATA на тренутном сајту. Тастатура: Alt+Shift+размак предлози · Alt+Shift+M мени · Esc затвори.

## Приватност
Целокупна провера одвија се унутар проширења. Не постоји ERATA сервер, налог, телеметрија ни аналитика, а проширење не тражи дозволу за приступ мрежи. Једини изузетак је необавезно, подразумевано искључено локално преформулисање, које може да пошаље једну реченицу на крајњу тачку на `localhost`/`127.0.0.1` коју сами изаберете. Подешавања, лични речник и увезени речници остају у `storage.local` и IndexedDB на вашем уређају. Поља за лозинке, е-пошту и картице, као и поља означена са `data-erata="off"`, игноришу се. Детаљи: [PRIVACY.md](PRIVACY.md).

## Инсталација
За сада се ERATA гради из изворног кода.
```bash
npm i && npm run dicts && npm run build
```
- **Chrome / Edge / Opera:** отворите `chrome://extensions`, укључите „Режим за програмере“, изаберите „Учитај распаковано“ и означите `dist/chrome`.
- **Firefox:** отворите `about:debugging`, изаберите „Учитај привремени додатак“ и означите `dist/firefox/manifest.json`.
- **Safari (преко Xcode-а, само macOS):** `xcrun safari-web-extension-converter dist/chrome`, затим изградите и покрените генерисани Xcode пројекат. Аутор Safari верзију **није тестирао**; погледајте [docs/SAFARI.md](docs/SAFARI.md).

## Clean-room
ERATA не садржи нити преузима ништа из кода, правила (XML/Java), података или порука програма LanguageTool или било ког другог коректора. Hunspell парсер, правила, детектор језика и алгоритми за предлоге написани су од нуле на основу јавних описа формата и општег знања о граматици и типографији. Уграђени речници су независни Hunspell пројекти са сопственим лиценцама ([dict/LICENSES.md](dict/LICENSES.md)). Цела метода: [CLEANROOM.md](CLEANROOM.md).

## Поређење са алтернативама (кратко и поштено)
Потпун приказ са изворима и напоменама: [docs/COMPARISON.md](docs/COMPARISON.md). Подаци о конкурентима прикупљени су са јавних страница 2026-11-18; све што је тамо означено као *непроверено* није потврђено.

- **LanguageTool, Grammarly, Microsoft Editor:** далеко шире покривање граматике у главним језицима (LanguageTool објављује број правила у хиљадама за енглески, француски, немачки, шпански и португалски), уз функције јасноће текста и преформулисања, Google Docs и мобилне уређаје. Подразумевано шаљу текст у облаке својих произвођача. ERATA то не ради.
- **Harper:** такође потпуно локалан и веома активан, али само за енглески.
- **Уграђена провера правописа у прегледачу:** у основном режиму је локална, проверава само правопис, без граматике.
- **Vale и LTeX+:** алати за програмере, за уређиваче и командну линију, а не проширења за прегледач.
- **Где је ERATA корисна:** локално проширење за прегледач које спаја проверу правописа и циљана правила за румунски, француски, шпански, португалски и енглески, уз враћање дијакритичких знакова, сопствена правила и увезене речнике. За румунски пронађени извори указују да су постојећа решења сразмерно слабија (у Microsoft Editor-у само правопис; LanguageTool румунски означава као неактиван); то одражава јавне изјаве, а не мерење поређењем.
- **Где ERATA заостаје:** има укупно око сто ручно написаних провера (груба процена, без ревизије). Мерења прецизности и обухватности на корпусу још нема. Мађарски није покривен, док га Microsoft Editor покрива, а Grammarly га наводи у бета верзији (дубина непроверена).

## Позната ограничења
- Знатно мање граматичких правила него код дуго успостављених провера; нема статистичког слоја за грешке у постојећим речима.
- Нема Google Docs (едитор на платну), нема мобилне верзије, нема интеграције са десктоп апликацијама и програмима за обраду текста.
- Аутоматски тестови у прегледачу раде само на Chromium-у. Firefox пролази `web-ext lint`, али овде није покретан у прегледачу. Safari није тестиран.
- Нема провере правописа за мађарски; нема уграђеног речника за немачки и италијански.
- Нема независне ревизије приступачности.
- Пројекат је нов (прва издања датирана су 18. новембра 2026.): још нема корисничке базе ни искуства у раду.

## Развој
Захтева Node.js >= 24.
```bash
npm i            # инсталира зависности
npm run dicts    # копира Hunspell речнике у dict/
npm test         # јединични тестови
npm run build    # прави dist/chrome и dist/firefox
```
`npm run pack` додатно прави `.zip` архиве.
